# 验证

检查范围由改动和项目要求决定，不从文件数量或流程模板机械推导。

| 改动 | 对应证据 |
| --- | --- |
| 文字或说明 | 事实、命令、引用与实际显示 |
| 业务／数据边界 | 关键行为、不变量、失败、并发与恢复 |
| UI 文案、布局和控件 | 真实界面、必要状态、输入与受影响公共调用 |
| 原生外壳 | 真实窗口、目标 DPI、系统入口与生命周期 |
| 性能与渲染 | 同条件基线、目标环境和连续过程 |
| 安装／运行库 | 最终载荷与隔离安装维护场景 |
| 配置工具 | 校验、分层来源、继承、冲突保存、私有范围及实际编辑 |

- 执行仓库中适用的检查，确认命令覆盖真实源码；测试观察行为，不镜像实现常量或固定措辞。可逆小改不为凑覆盖新增无意义测试。
- 按风险选择加载、空结果、失败、无权限、重复操作、取消、快速切换和恢复，保留用户已有工作。记录未提交差异，提交号不完整代表当前工作树。
- 编译产物或资源变化后重建，并让证据对应最终版本。原生宿主与 Web 内容分别检查；DOM、常量、事件路由和构建成功不替代真实画面与输入。
- 配置中的主题、视口、DPI 和输入方式提供目标集合，不授权跳过必要检查。环境不支持时准确记录未验证项，不能配置成通过。
- 性能问题观察交互中与停止输入后的过程。稀疏截图不冒充完整视频，采集帧率不等于实际渲染帧率，记录工具与采集层限制。
- 写测试使用隔离可恢复资料。真实资料需要任务授权，截图与日志不进入公开源码。保存文件引用必须存在，不能编造证据位置。
- 移动端区分 Debug／正式签名、模拟器／真机包，升级保留身份与签名连续性。没有物理设备验证时不能宣称真机通过。
- 需要独立验收时，明确检查范围并使用环境已提供的独立审查能力。本技能仅维护结果标准，不负责模型、会话、桌面锁或修复轮次编排，也不要求所有小改启动独立检查。
- 相关检查通过后继续交付；只有新变更、失败或未解决的问题才扩大或重复验证。报告改动、实际证据与使用限制，不将安装、发布或清理自动加入任务。
