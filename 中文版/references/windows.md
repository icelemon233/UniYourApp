# Windows

保留项目已有框架、产品身份与安装方式，结合[共用 UI](ui.md)处理内容。只有受影响的窗口、系统入口或安装工作才读取对应章节，普通界面修改不自动启动升级。

## 窗口、DPI 与输入

- 区分 DIP、物理像素、浏览器缩放和文字缩放，不重复应用比例。坐标处理覆盖负坐标显示器；配置只给设计偏好，不替代真实命中测试。
- 自定义标题栏保留拖动、双击最大化、还原、贴靠、系统菜单、键盘和缩放。交互控件不成为拖动区，最大化／还原图形、名称、提示与实际状态同步。
- 明确按下和松开由系统还是应用负责，在失去捕获、取消、失活或移出目标松开时清理状态。保留系统贴靠语义，验证边角与窗口按钮或 WebView 重叠时的缩放优先级。
- 原生子窗口不一定沿用父窗口的命中处理。对应真实指针、DPI、接收方与前后边界，用受支持的宿主方案修复；父窗口返回值正确或透明覆盖层存在不构成结果证据。
- 最大化采用所在显示器工作区及真实边框，不硬编码任务栏高度。检查底部内容、自动隐藏和还原边界；CSS 圆角不等于原生外框已修复。
- 原生标题、菜单与 WebView 从同一主题选择适配各自语义角色。系统图标、标题图和托盘图可能来自不同路径，核对实际选中的分辨率与可见结果。

## 导航与生命周期

- 按项目用途采用导航，不强制侧栏或固定窗口模板。覆盖式导航不意外挤动内容，键盘焦点、菜单与拖动仍在时保持可操作；保存明确偏好而非瞬时悬停状态。
- 区分最小化、关闭、隐藏到托盘和退出进程。按配置或项目约定执行，确认恢复入口有效后才隐藏。重新打开或第二次启动不能意外启动重复服务或写入者。
- 真正退出先处理草稿、传输、后台工作、连接和设备恢复，失败时提供可处理状态。异步收尾与最终销毁分开调度，避免同步完成的 await 导致关闭回调重入。
- 托盘菜单保留主题、DPI、键盘、焦点、Esc 和外部点击关闭。任务栏与通知区托盘分别检查，退出后释放菜单、图片句柄和后台实例。
- 有本地服务时验证独占绑定、浏览器允许的端口和实际实例／会话身份，不能只看一个端口或任意 HTTP 200。桌面启动、手机配对与维护权限分开。

## 资源与安装

- 分离显示名、发布者、稳定 ID、安装范围和资料位置。资源相对程序或框架定位，不依赖工作目录、源码树或自解压临时目录。改名与升级保留必要身份连续性。
- 原画、母版与派生资源记录来源。按实际入口与 DPI 导出图标，分别核对 EXE、窗口、任务栏、托盘、安装器、卸载器和快捷方式。构建验证与真实显示是两项证据。
- 遇到旧图先查运行路径、版本、快捷方式与帧选择，不默认清空全系统缓存或修改其他应用入口。QA 实例采用独立身份，不能仅凭同样的图标猜操作对象。
- 核对最低系统、架构、SDK 资产和运行库，使用最终载荷冷启动新初始化路径。不要从开发机随手复制 DLL 掩盖部署问题，GUI 不意外弹控制台。
- 保留安装引擎的事务、权限、取消和卸载能力，自定义界面必须驱动真实选项。写入前校验路径、范围与归属，拒绝危险根目录及破坏边界的链接，不覆盖无关文件。
- 当前用户与全机安装分别识别。升级保留范围、路径及快捷方式选择，交接失败保留草稿。Unicode、参数转义、中文和空格路径实际验证。
- 维护先等待本应用正常退出与任务结束，核对真实进程身份；超时或设备恢复失败不能变成强杀。取消和失败验证程序、注册信息与所属入口恢复，保留有效恢复资料。
- 卸载依据所属清单移除程序和入口，保留用户设置、接收文件和无关资料，不递归清空整个安装目录。共享系统运行库不按应用文件事务随意回滚或卸载。
- 已授权替换日常安装前核实匹配旧版的完整恢复载荷。安装事务回滚与安装成功后的降级分开，后者需要确认程序／数据兼容，不删资料迁就旧版。

## 验证

使用隔离目录、数据、注册、快捷方式和锁进行相关安装测试。按影响范围实测原生拖动、缩放、贴靠、托盘、键盘与目标 DPI；UI 线程重任务要观察实际响应。核对最终产物版本、哈希、依赖和入口，说明源码、模拟、真实操作、物理设备与安装后结果的区别。
