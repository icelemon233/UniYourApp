# Web

与[共用 UI](ui.md)配合使用，只读取受影响的部分。

## 布局、控件与导航

- 先确认实际显示层：原生控件、组件库、自定义包装、首屏 HTML、应用渲染层或无脚本页面。检查真实 DOM 插槽和当前 SDK，不混用不同框架的同名 API。
- 同类页面共用外层宽度、边距和断点，正文窄列是有用途的例外。边距与滚动条占宽只计算一次，整页轨道位于工作区末端；不硬编码操作系统滚动条宽度。
- 保留 URL、深链接、刷新和前进后退语义，局部动作用按钮。长名称与导航各有可用宽度，窄屏按阅读顺序重排，软键盘、安全区和固定栏不遮住输入或提交。
- 收缩与换行约束放在实际参与布局的外壳。日期区间字段和连接词作为完整单元，伸展槽的空白不自动变成链接或手型区域。
- 同组控件量取可见外框、字框、箭头、图标和命中区，覆盖组件库生成的按钮与原生日期字段。不用宽泛的类选择器把根节点尺寸同时套到内部插槽。
- 自定义选择菜单保留真实表单值、原生回退、可访问名称、选中状态、键盘与焦点返回。按真实触发器和可用区域限制面板，换向或内部滚动，单加 offset 不能解决过高菜单覆盖入口。
- 查明滚动条来源，按悬停和拖动时最大轨道预留空间。每个区域一根轨道，保留真正的嵌套滚动和位置恢复；菜单滚轮不意外带动页面。
- 空状态按所属区域布局，整页网格空状态跨列，纵向伸展需要真实父级空间。媒体覆盖操作属于视口，不增大图片的滚动范围；可编辑字段与原生媒体保留自身快捷键。
- 字体、语言与无障碍覆盖组件库默认按钮、清空名称、菜单和错误。CSS、框架和 DOM 无障碍层对焦点可见性的判断一致，验证真实首次点击，而非先点空白后再检查。

## 启动与多渲染层

- 共享颜色、字体、尺寸与间距从一个来源生成。交接读取最新主题、URL、草稿、筛选、分页与滚动状态，不能重放启动快照；接管后释放旧监听与浮层。
- 渐进增强保留可用的原生表单。提供无脚本阅读时，内容完整，只显示真正可用的操作。通过 DOMParser 移入内容时避免激活仅属于 noscript 的隐藏样式。
- 区分网络、运行时初始化、界面构建和解码。重构建前先提交轻量反馈，不能在同一帧做完重活才显示骨架。已可读内容和同页刷新不强制回到骨架，不为动画设置最短等待。
- 骨架沿用真实结构、主题和响应式，不提供假控件，只播报一次加载。图片成功或失败均结束加载；取消、错误、超时与导航均能退出占位，只有当前请求能替换内容。
- Flutter Web 等多层实现按已安装 SDK 核对参数。局部文字样式可能丢掉回退字体，前景色可能重新产生 overlay，菜单定位可能在空间不足时反向覆盖入口，必须看实际字形、状态与面板边界。

## 性能与图表

- 在目标浏览器、视口、DPR、刷新率与渲染器下比较同条件基线。空闲绘制次数、自动滚轮频率和视频编码帧率不能证明应用流畅度。
- 按真实瓶颈处理请求、主线程、布局、绘制、解码与重复重建。虚拟列表保留稳定身份、锚点、焦点和选区；收藏等元数据更新保留已加载范围，不能只记住 scrollTop 却退回首批内容。
- 尺寸观察、滚动条显隐与依赖宽度的行高可能形成反馈循环。连续观察停止输入后的状态，稳定尺寸来源，不以隐藏轨道或裁切消除现象。
- 渲染键不使用测量尺寸或浮点位置。主题插值导致整页重建时先测量，再选择原子切换与局部过渡。引擎替换要核对字体、资源版本、MIME、能力回退和 worker 条件。
- 图表适应实际可用宽度，标签不随大 viewBox 缩成小字。缺失、零值和估算分别表达；不造数据。文字使用当前背景，容量条标签相对全容器定位，小块内缩不能变成负尺寸。

## 验证

按变更实测鼠标、键盘、适用触控、窄屏、长值、文字放大和主题。涉及启动交接时覆盖冷启动、快速导航与最新草稿；涉及原生宿主时另做宿主验证。记录实际检查层、测量条件和工具限制。
