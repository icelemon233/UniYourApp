# 共用 UI

**避免不必要的次要标签和描述，让布局本身来传达信息。**

## 信息与结构

- 从用户当前任务需要的信息和动作开始，用分组、对齐、距离、层级与留白表达关系。不要为每个区域、卡片、记录或控件补副标题、眉题、徽章和解释句。
- 次要文字须帮助识别内容、理解必要条件、消除歧义或完成动作；只有“增加新信息”还不够。字段名、按钮、可见值或布局已经表达时省略重复说明。
- 保留操作名称、表单标签、单位、错误与无障碍名称。图标按钮可以只提供可访问名称，不必常驻一行解释。删除文字时同步移除专属包装、间距与保留高度，并检查加载和导航后不会恢复。
- 共用规则不规定品牌、人物、固定色板或统一窗口模板。读取项目自己的设计变量和私有偏好，保留其已确认方向；局部修复不扩成全局换肤。

## 真实几何与视觉角色

- 颜色、字体、间距与状态由项目内的单一来源管理。区分表面、正文、辅助、链接、主操作、选中、焦点和危险角色，背景变化时同步其上的文字与交互状态。
- 分组边界有实际用途，普通内容不层层套卡片。输入、菜单、浮层、选中和警告保留功能性表面。修改底色后重新核对间距，不能留下不明的大块空白。
- 相邻距离由一个层级负责，计算父级 gap、子级 margin、组件内距、行框、分隔线与命中区的叠加。分别测量可见外框、字形和点击范围，不用负偏移、裁切或缩小目标凑对齐。
- 长文字、不同语言和文字放大时允许增高与重排。值、装饰箭头和可点击清除控件各自留位。需要等高时检查内部背景与弹性内容，不能靠空说明行或填充节点实现。
- 字体覆盖保留中西文回退，用生产字体确认真实字形和字重。功能图标、应用身份和插画各有用途，应用运行时不依赖技能目录中的资源。

## 输入与反馈

- 同一决策组有明确主次，按钮几何一致，导航保留链接／平台语义。选中在悬停和按下时仍可辨，焦点、边框与字重变化不推动布局。
- 区分真实焦点和键盘定位提示。鼠标焦点、修饰键和系统快捷键不自动等于键盘导航；不通过全局隐藏焦点或强制失焦解决残留。
- 字段标签、值、必填、禁用、校验和错误保持关联。菜单和弹窗保留正确的 Tab、方向键、Enter、Space、Esc、适用的外部关闭及焦点返回。一个完整交互对象只绘制一致的焦点反馈。
- 检查实际背景上的可读性：普通文字至少 4.5:1，必要控件与焦点边界至少 3:1。装饰分隔线不能替代可辨认边界；主题和自定义背景分别核对。
- 加载保留草稿与可读内容，成功必须发生在操作真正完成之后。没有其他可见结果的复制等动作提供简短反馈，失败清除过期成功提示。
- 只有有效有限总量和正确当前值才使用确定进度。等待、不定进度、取消、部分完成和完成分别表达，不将无效值钳制为假 100%。
- 动效服务反馈，尊重减少动态效果并在任务结束后停止，不为数量要求添加动画。平台明确的即时反馈优先于一般过渡。

## 修复与检查

从真实界面复现问题，追溯公共实现和全部受影响调用。不能用更多解释掩盖层级或间距错误。按问题覆盖必要的主题、长短内容、窄空间、文字缩放与输入状态，常量、DOM 存在性和一张截图只能提供部分证据。
